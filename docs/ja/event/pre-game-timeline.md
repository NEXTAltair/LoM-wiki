# {{ $frontmatter.title }}

このページは、物語が始まる前(序章「唐門を知っているか？」より前)に既に起こっていた江湖の大事件をまとめたものです。これらの出来事は各人物・陣営のページに「二十年前」といった回想の形で散在していますが、本ページでは時系列順に整理し、各陣営の現状に至る経緯を把握しやすくしています。

時間の表記は原文の相対的な言い回し(「約N年前」)をそのまま用い、ゲーム内の確定した年に無理に換算していません。史実と照合できる部分(靖康の変など)のみ、実際の西暦年を併記しています。物語開始後に起こる出来事(風雨山武林大会を含む)は本編の範囲であり、[メイン・サブシナリオ年表](/ja/event/story-branch-timeline)を参照してください。本ページには含みません。

## 靖康の変と南遷

北宋は[靖康の変](https://zh.wikipedia.org/zh-tw/%E9%9D%96%E5%BA%B7%E4%B9%8B%E5%8F%98)(1125-1127)で中原を失い、皇室は臨安へ南遷した。これが[大宋](/ja/people/factions/song-dynasty)である。以後、大宋は[大金](/ja/people/factions/jin-dynasty)・西夏と隣接し、領土はたびたび金国の侵攻を受けており、[趙方](/ja/people/characters/soldier31)と[丹霞子](/ja/people/characters/special404)が襄陽戦線を守っている。

## 武林三次総動員

[南宮橫](/ja/people/characters/special104)が寿宴で述べたところによれば、彼の100年の人生の中で武林総動員は3度あった。

### 第一次：汴梁救援

盟主南宮智は大勢を率いて汴梁に赴き金兵を防いだ。丸2年間戦ったが、欽宗皇帝・徽宗皇帝は捕らえられ、汴梁は陥落した。南宮智は大勢が既に決したと見て、武林の同道に謝罪して盟主を辞し、同盟を解散した。宋高宗が応天府で即位した後、武林人士を編成する意思を示し、盟主に軍の再編成と奉国軍節度使劉光世麾下への参集を命じ、抗命すれば軍を送って攻め滅ぼすとした。これが江湖と朝廷の不和の始まりである。

### 第二次：岳飛の北伐

[岳王爺](https://zh.wikipedia.org/zh-tw/%E5%B2%B3%E9%A3%9E)が現れ、北伐を請願した。江中で武林の知恵者曾文先生と共に濁酒を飲み、山を出て世に入り河山を回復するよう請うた。曾文先生・紅篷王を筆頭に、一人は文の盟主、一人は武の覇王として文武を分掌し、岳王爺と共に失地を回復していった。だが十二道の金牌により、この忠君愛国の名将は呼び戻され、殺された。曾文先生は王爺を諫めようとして途中で失踪し、紅篷王は出家して法号を春眠とした。江湖人は再び朝廷を信じないと誓った。

### 第三次：決戦極楽教

約二十年前、西域の[極楽教](/ja/people/factions/elysium-school)が武林に大きな脅威をもたらし、西夏と内応して河西回廊を奪い、大宋・金国の咽喉を握ろうとしていた。[嵩山派](/ja/people/factions/mount-song-sect)の高僧の感召により武林各派の首領はかつての対立を捨て、新任の武林盟主[龍淵](/ja/people/characters/special2)の指導のもと心を一つにして[極楽教](/ja/people/factions/elysium-school)を討伐した。詳細は[決戦極楽教](/ja/event/stories/決戰極樂教)を参照。

戦いの最終段階では、[唐中翎](/ja/people/characters/master)が毒薬を飲んで力を強引に高め右護法を討ち取ったが後遺症が残り、左護法の[李元棄](/ja/people/characters/special213)は青城の[趙逵](/ja/people/characters/special403)を打ち破って逃亡し、盟主[龍淵](/ja/people/characters/special2)は天觴剣で万悪の首魁「快活王」こと[李仁友](/ja/people/characters/other7)を誅殺したものの戦後行方をくらませた――義兄弟である金国の翼王[完顔珣](/ja/people/characters/special819)が援軍の約束を違えて傍観していたことを知り、責めには行ったが手を下せず、自ら右腕を切り落として詫びとし、身分を隠して[丐幇](/ja/people/factions/beggar-gang)の中に紛れ込んだ。

この戦いで唐門と嵩山は共に大きな打撃を受けたが、嵩山はなお世人から尊敬されたのに対し、唐門は皆から叩かれる犬扱いされるようになった。

## 決戦極楽教前後の伏線と余波

- **[青城論道](/ja/event/stories/青城論道)**(二十数年前)：崆峒の[火龍仙君](/ja/people/characters/special204)、全真の[丘處機](/ja/people/characters/special209)、[郝大通](/ja/people/characters/other4)、青城の[鄒博](/ja/people/characters/special201)、[趙逵](/ja/people/characters/special403)が一堂に会し論道した。火龍真君が道書を曲解したことが、後に趙逵の道心が沈淪し地獄道法王に堕ちる遠因となった。
- **[唐門](/ja/people/factions/tang-men)の刑場破り**：掌門就任前の[唐中翎](/ja/people/characters/master)が、少年の[唐布衣](/ja/people/characters/brother1)・[唐錚](/ja/people/characters/brother2)を率いて、権貴に罪を得て斬首されかけていた[唐陞](/ja/people/characters/brother3)を刑場から救い出した。これは美談だが、以後十数年にわたり唐門は朝廷に目の敵にされ、[大宋](/ja/people/factions/song-dynasty)皇帝が[上官世家](/ja/people/factions/shang-guan-family)に唐門弱体化を命じる遠因となった。
- **[点蒼派](/ja/people/factions/dian-cang-sect)の唐門への挑戦**：決戦極楽教の後、病を押した[唐中翎](/ja/people/characters/master)が挑んできた[点蒼派](/ja/people/factions/dian-cang-sect)に応戦し、[無名](/ja/people/characters/special406)(点蒼剣聖)を打ち倒したが唐門側も大きな痛手を負った。[南宮世家](/ja/people/factions/nan-gong-family)家主の仲裁により、掌門は剣聖の命を取らず封剣隠退させることで点蒼の撤退と引き換えた。同じ頃、師娘[唐鹿](/ja/people/characters/other10)が世を去った。
- **[江陵府官道の穀物奪取事件](/ja/event/stories/江陵府官道劫糧案)**(十数年前)：かつて極楽教が[南宮世家](/ja/people/factions/nan-gong-family)の裏切り者南宮禹に命じて穀物を奪わせたと伝わる事件。事が露見して南宮禹は自害し、[南宮世家](/ja/people/factions/nan-gong-family)は長年濡れ衣を着せられた。真相はのちに[趙活](/ja/people/characters/player)と[唐布衣](/ja/people/characters/brother1)によって明らかにされる。
- **[錦香宮](/ja/people/factions/jin-xiang-palace)の洞庭移転**(約十年前)：もとは錦香閣といったが、杏花仙[瑞杏](/ja/people/characters/girl1)が宮殿を弟子入りの礼として献上し、閣を挙げて洞庭湖に移り住んだ。
- **[白風峒変乱](/ja/event/stories/白風峒變亂)**(極楽教滅亡後、数年～十年の間。この十年で江湖最大の事件)：逃亡していた極楽左使が「[李元棄](/ja/people/characters/special213)」と名乗り、郴州で民心を煽って挙兵。最終的に[唐布衣](/ja/people/characters/brother1)、[解無塵](/ja/people/characters/special808)、[夏侯蘭](/ja/people/characters/girl5)ら五人の江湖侠士の手で討ち取られた。
