## イベントの時期
- 第三年10月中旬に始まり、日付の判定なく続けて進む。<br>
- 前段は[四師兄、商いの長旅へ](/ja/event/detailed_description/3-08-1-四師兄遠遊經商) (8月上旬)・[大会の招待状](/ja/event/simple/3-08-2-大會請帖) (8月中旬、同行者を誘う)・[武林大会へ向かう](/ja/event/simple/3-09-1-前往武林大會) (9月上旬)・[錦香宮イベント集](/ja/event/simple/3-09-3-錦香宮事件集)。<br>
- 子イベントの一覧は[武林大会](/ja/event/simple/3-10-2-武林大會)。このページは子イベントの流れと、大会の中で立つフラグと判定を 1 ページにまとめる。会話だけが変わる判定は省く。<br>

## 大会中に立つフラグ

大会の中で立ち、後の段や大会の後で判定されるもの。

| フラグ | 立つ場面 | 判定される場面 |
| --- | --- | --- |
| 🚩錦香宮から追い出された | １、錦香宮からの追放で「好漢は目前の損を被らず、ずらかる」 | ４、唐門の決断 (「錦香宮を支持する」が開く条件の一つ: 追い出されていないこと) |
| 🚩温夫人の正体を知っている | １、錦香宮からの見送り (温夫人の付託を最後まで進める) | ３、各門派への挨拶の錦香宮 (人間道好感+1) |
| 🚩上官螢が日本へ嫁いだと知る | ２、上官螢への挨拶 (結縁者なしか魏菊と結縁) | ３、上官対策 (想い人が上官螢なら挑む前の選択が変わる)・４、南宮世家への哀悼 (🚩大会後に上官螢と約束) |
| 🚩武林大会で瑞笙を殴った | ２、瑞笙への挨拶 (想い人が唐黙鈴で、唐黙鈴と結縁していない) | ３、各門派への挨拶の孤雲山派 (開かなくなる) |
| 🚩上官隼に挑戦 | ３、上官隼との決闘 | ３、点蒼の逆徒 (葉雲舟は自分自身の名義で出場) |

| 🚩大会後に上官螢と約束 | ４、南宮世家への哀悼 | ６、宿屋に入る |
| 🚩飛石幇と和解 | ５、唐衫の反論 | ５、泥教襲来 (🚧未実装：飛石幇の加勢) |

大会より前に立ち、大会の中で何度も判定されるもの: 🚩錦香宮へ客として赴く ([武林大会へ向かう](/ja/event/simple/3-09-1-前往武林大會))・🚩金烏上人が死亡 ([金烏との決闘](/ja/event/simple/3-05-1-對決金烏))・🚩崆峒派の掌派人・同行者 ([大会の招待状](/ja/event/simple/3-08-2-大會請帖)ほか)・🚩画中仙に挑戦 ([画中仙に挑戦](/ja/event/simple/3-09-3-挑戰畫中仙))・🚩石幇主夫婦の仲直りを助ける・🚩臥雲崗で唐衫が大師兄に同行 ([臥雲崗イベント](/ja/event/simple/3-01-2-臥雲崗事件))。
