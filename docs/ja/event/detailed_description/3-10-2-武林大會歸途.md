## 基本の流れ

**カテゴリ**：メインシナリオ<br>
**発生時期**：第三年10月上旬〜中旬 ([錦香宮に泊まる](/ja/event/simple/3-10-1-留宿錦香宮)の後)<br>
**発動条件**：メイン進行で自動発生<br>

1. **一同、家路につく (眾人啟程回家)**
   + 性情≦40：団結+2、会話が追加される
   + 分岐：[南宮深](/ja/people/characters/special102)好感≧20、または[崆峒派](/ja/people/factions/kong-tong-sect)の態度が友好、
     または崆峒の掌派人になっている、または[上官螢](/ja/people/characters/girl4)と結縁している → **馬車での見送り**
   + 上記以外 → **廃寺で雨宿り**
2. **馬車での見送り (馬車送行)**：条件を満たす場合、次の順で1つが発生する
   + [南宮深](/ja/people/characters/special102)好感≧20：南宮深が馬車を用意する
     + 崆峒派の態度が友好／南宮家が敵対／武林大会の投票結果が敵対：それぞれ会話差分
     + 品性≧40：処世-1、性情+1
     + 品性＜40：処世+1、性情+1
     + 処世＞40：南宮深好感+1
     + 処世≦40：南宮深好感+2
     + 👉「女遊びの世話もしてくれるのか」(処世＞40かつ道徳≦40)：南宮深好感+3
   + 崆峒派の態度が友好：[丹霞子](/ja/people/characters/special404)が馬車を用意する
3. **廃寺で雨宿り (破廟避雨)**(第三年10月中旬)：団結+1、心相+10
   + [唐默鈴](/ja/people/characters/girl0)が同行：会話が追加される
   + [龍湘](/ja/people/characters/girl8)を保護している：会話が追加される (学問≧40 で龍湘好感+)
   + [樊嘯天](/ja/people/characters/special4)が唐門に加入している：会話が追加される
   + 休憩画面が開く (セーブ可)
   + 以下のいずれかを選ぶと、終了後に**焚き火の会話**へ進む
     + **▲賭博**：**🎲**(上限30、➕加値：暗器)
       + **🧾【＜50】ズボンを剥がれる**：称号「褪褲俠」を獲得。[唐默鈴](/ja/people/characters/girl0)が同行していると勝った金を分けてくれる (心相+20、銀両+2000)
       + **🧾【＜90】勝ちも負けもなし**：暗器+2
       + **🧾【≧90】まさかの勝ち**：銀両+600×3、団結-1×3
     + **▲腹一杯食べて寝る**：処世+1、心相+20
       + [樊嘯天](/ja/people/characters/special4)が唐門に加入している：心相+10、樊嘯天好感+2
     + **▲目を閉じて思案を沈める**：心相判定
       + 心相≧60：武学+5、修練画面が開く
       + 心相＜60：影響なし
4. **焚き火の会話 (火邊對話)**：団結-2
   + 腹一杯食べて寝ていた場合：会話と描写に差分
   + 処世≧60：「性別すら間違える」会話差分
   + 皆が大笑いする：団結+2
   + 処世≧40：「姓すら持たない」弁舌+1
   + 道徳≦40：「良い物を食っている」処世+1
   + 品性≦40かつ処世≧60：「もっと下っ端に見える」道徳-1、品性-1、処世+1、弁舌+1
   + 武林大会の投票結果が敵対：会話差分
   + [唐衫](/ja/people/characters/special811)が唐門に加入している：会話が追加される
   + [龍湘](/ja/people/characters/girl8)を保護している：会話が追加される
   + 道徳≧40：品性≧60 で会話が追加される
   + 道徳＜40：処世≧60 で会話差分
   + **古参の外弟子が離脱を考える** → **📖選択**
     + 👉「脅す」：道徳-2、弁舌+1、品性-1、処世+1
     + 👉「言葉を尽くして説得する」：弁舌+1、品性+1、処世-1 → **🎲どう応じるか**(上限50、➕加値：弁舌)
       + **🧾【＜70】言葉に詰まる**
       + **🧾【≧70】説得力十分**：団結+1
     + 👉「引き留めるより歌おう」：処世+2、性情+1、品性+1、心相+10
       + [唐默鈴](/ja/people/characters/girl0)が同行し、想い人が唐默鈴の場合：唐默鈴好感+2、心相+20
5. ➡️ 唐門到着後は[唐門への帰還](/ja/event/detailed_description/3-11-1-回到唐門)(第三年11月上旬)へ続く

## 備考
