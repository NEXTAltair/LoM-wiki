## 基本の流れ

**カテゴリ**：メインシナリオ(青城留学の終盤・想い人＝[葉雲裳](/ja/people/characters/girl2)ルート)<br>
**発生地**：青城派<br>
**発生時期**：第2年9月下旬頃<br>
**前提**：[青城での療養](/ja/event/detailed_description/2-08-5-青城療傷)の日常イベント群
([唐芳問診](/ja/event/simple/2-08-6-唐芳問診)・[葉雲裳秘笈2](/ja/event/simple/2-08-7-葉雲裳秘笈2)・
[青城遊覽](/ja/event/simple/2-08-8-青城遊覽)・[四師兄行商](/ja/event/simple/2-09-2-四師兄行商))を
一通り経た後に発生。本イベントをもって青城留学は終わる<br>

1. **📜段考の場：** 鄒掌門・不平長老・懐素長老が、退隠していた鐵冠道人も交えて段考(継承試験)の
   進め方を話し合う最中、鐵冠道人が「新しく取った弟子」を紹介する
   + 葉雲舟・葉雲裳がその弟子の顔を見て、[段智秀](/ja/people/characters/special833)だと気づく
2. **📜対峙：** 主人公が殴りかかるが「私が片手で相手をしてやっても、君は本公子の敵ではない」と
   一蹴される[^1]
   + 葉雲裳が「あいつの内功は深いから、攻撃しても逆に自分が傷つくだけ」と主人公を止める
3. **📜糾弾：** 主人公が、南宮秀の名を騙って盗賊を買収し唐門を夜襲させた黒幕は段智秀だと
   鄒掌門・懐素長老の前で告発する
   + 段智秀は「南宮己などという腹心は知らない」としらを切り通し、共犯の南宮己が既に
     [唐錚](/ja/people/characters/brother2)(二師兄)に捕らえられていることには触れない
   + 鐵冠道人は自分の弟子の肩を持ち、一時は主人公・葉雲裳を拘束しようとするが、
     段智秀が「今回だけは大目に見る」と恩着せがましく解放する
   + 段智秀は表向きは寛大さを演じつつ、裏では葉雲裳に降伏を迫る
4. **📖選択：青城を離れるべきか** 雷が止んだ頃合い、二人きりで今後を相談する
   + **📖選択：今すぐ青城を離れる**（TODO: 未収録。段智秀に既に包囲網を敷かれている
     可能性が高く、迂闊に動けば裏をかかれるという趣旨の会話がある）
   + **📖選択：ひとまず留まる**：鄒掌門が山にいる限り段智秀も迂闊には動けないと判断し、
     青城に留まることを選ぶ → イベント終了
