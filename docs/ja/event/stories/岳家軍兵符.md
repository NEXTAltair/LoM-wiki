# {{ $frontmatter.title }}

[葉雲舟](/ja/people/characters/special3)・[葉雲裳](/ja/people/characters/girl2)兄妹の曾祖父は、抗金の名将・武穆王[岳飛](https://ja.wikipedia.org/wiki/%E5%B2%B3%E9%A3%9B)の子、岳雲の配下にいた腕利きの大将の一人だった。

<br>

伝えによれば、高宗が立て続けに十二道の金牌を下し、岳飛は忠義を全うするため自ら死に赴いた。ただ心残りは、抗金の大業がまだ成っていないこと。もし兵権が奸臣に奪われれば、大宋はもはや立て直しようがなくなる。そこで岳家軍の主力を分散させ、財宝を山中に隠し、鋳造した鉄の兵符を長子・岳雲に預けて保管させた。いつの日か兵符を掲げて旧部下を号令し、護国の志を継承できるようにと。

<br>

ところが岳雲は、思いもよらず父より先に命を落とす。危難の中で兵符を部下に託し、江湖に身を隠して、武穆王の後人が取りに来るのを静かに待つよう言い残した。その部下(葉家の祖先)はそれ以来姓名を隠して山林に隠棲し、代々兵符を守り抜いた——葉家はこの誓いを守るため自らの姓すら捨て、曾祖が仕えた主君・岳雲を記念して「葉雲」を姓とした。家宝の剣「聴雲剣」も「岳雲に従う」という意味である。

## 分かれた一族：野利察漢

しかし旧岳家軍の後裔がみな誓いを守り抜いたわけではない。[李元棄](/ja/people/characters/special213)(本名・野利察漢)の祖先の一脈も同じ岳家軍の後裔でありながら、岳飛の死後に心が冷え込み、仇を報い恨みを晴らすため軍を裏切って西夏に投じた。この一脈はのちに[極楽教](/ja/people/factions/elysium-school)左使となり、[決戦極楽教](/ja/event/stories/決戰極樂教)で青城の[趙逵](/ja/people/characters/special403)を撃破したものの重傷を負って逃亡し、数年後に化名して再び姿を現した。

## 秘密の露見と葉家の滅門

この秘密は百年近く守られたが、ついに人に知られてしまう。宝蔵と兵符は一族滅亡の災いを招いた。[葉雲裳](/ja/people/characters/girl2)の父母は、兵符が誤って賊の手に渡り、民が塗炭の苦しみを味わうことをただ恐れ、兵符の印を愛娘の背中に焼き付けたうえで、兵符本体を破棄した。

<br>

まもなく[白風峒変乱](/ja/event/stories/白風峒變亂)が勃発する。葉家は族叔の[李元棄](/ja/people/characters/special213)を朝廷に密告し、身敗名裂にして民心を失わせようとしたが、かえって朝廷に抄家され、一族は滅門の災いに遭った。[葉雲舟](/ja/people/characters/special3)・[葉雲裳](/ja/people/characters/girl2)兄妹はこうして孤児となった。

## 李元棄の贖罪

流離した葉家兄妹は、南の湖南にいる族叔の[李元棄](/ja/people/characters/special213)を頼ったが、顔も見せずに門前払いされた。実は彼らを巻き込むことを恐れ、葉家忠良の名を守りたかったのだ。その夜、彼は独り軍営を抜け出し、[葉雲裳](/ja/people/characters/girl2)が既に臨終間際にいるのを見つけると、「九泉丹」を飲ませて救い、忠義より自分の命を重んじるよう諭した。

<br>

最後、[李元棄](/ja/people/characters/special213)は[唐布衣](/ja/people/characters/brother1)ら五人の手に敗れ、白風峒変乱の終幕で命を落とした。
