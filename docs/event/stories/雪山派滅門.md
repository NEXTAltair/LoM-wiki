# {{ $frontmatter.title }}

雪山夏侯掌門與上官世家家主[[上官隼]]是過命的交情，曾訂下指腹為婚之約，膝下獨生女便是後來的[[夏侯蘭]]。

<br>

起因是一件無關緊要的口角。雪山派弟子行走江湖，在客棧遇上[[崆峒派]]中人，那崆峒弟子取笑雪山派入冬不如崆峒冷，雙方一言不合便動了手。刀劍無眼，一不留神便打死了人，兩邊都殺紅了眼，各自找更多人來討公道，事情越鬧越大。

<br>

雪山派向[[上官世家]]求援，[[上官隼|上官家主]]卻以路途遙遠為由推託，冷眼旁觀。最終雪山派被崆峒派滅門，掌門獨生女[[夏侯蘭|夏侯梅]]被抓走，改名[[夏侯蘭]]，成為崆峒奪魄門嫡傳女弟子。

## 餘波

肇事的飛天門弟子死在雪山亂戰之中；而親手殺死掌門的凶手，則在[[夏侯蘭]]武功大成後被她擰下頭顱，懸屍半雨屏曬成乾屍，算是報了殺父之仇。

<br>

雪山派遺址盡數被大火燒盡，又遭大雪掩埋，除了梅花樁的五塊大岩石與一棵雪樹，什麼也沒留下。弟子[[第三香]]僥倖逃過一劫，其後輾轉到崆峒山與[[夏侯蘭]]重逢，則是後話了。

<br>

指腹為婚的約定，也隨著雪山派滅亡而不了了之。

## 備註

- 遊戲中的大雪山位於甘肅一帶、崆峒山附近，與現實四川的大雪山山脈相去甚遠，鳥熊表示純屬參考，非寫實地理[^1]
- 若走[[夏侯蘭]]線，[[趙活]]會成為雪山派大弟子
- 2025年「為心上人送上色紙」投票活動中，官方釋出雪山派後日談：在[[夏侯蘭]]的帶領下，雪山派日後重新崛起，成為武林七大門派之一，桃李滿天下[^2]
