# OLD_TERM 検出の除外リスト。行に含まれていればその行を旧訳語判定から外す。
# 1行1パターン (部分一致)。# 始まりはコメント。
#
# 【登録してよいもの】「訳 (原文)」の原文併記など、bad 側の語がそこに出るのが
# 正しい書き方である行に限る。
# 【登録してはいけないもの】地の文に残った旧訳語。ゲートを黙らせるために使うと
# STALE_TERMS を足した意味がなくなる。
#
# 括弧の中身を機械的に判定して除外する方式は採らない。「括弧内にカナが無ければ
# 原文併記」のような推定は `（旧訳：叛徒）` `（叛徒処刑）` のような漢字だけの
# 日本語注記まで巻き込み、旧訳語を見逃す。除外は推定せず1件ずつ登録する。
#
# 新規に追加する場合は、なぜその表記が正しいのかを必ずコメントで書くこと。
